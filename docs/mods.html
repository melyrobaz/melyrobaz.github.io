Installer des mods

Un mod est un plugin que vous ajoutez à FloralPlayer : une DLL (.dll) ou un script (.rhai). Aucun redémarrage n’est nécessaire.

N’installez que des mods de confiance

Une DLL est du code natif qui s’exécute avec vos droits, comme n’importe quel programme. Les scripts .rhai tournent dans un environnement restreint, mais restent à vérifier avant usage.

1. Installer

Trois façons, au choix :

  • Préférences → Plugins → « Installer un mod… » puis choix du ou des fichiers.
  • Glisser-déposer le fichier .dll ou .rhai sur la fenêtre.
  • Palette de commandes (Ctrl+K) : « Installer un mod… ».

Le fichier est copié dans %APPDATA%\Floral Player\plugins, puis le dossier est relu : le mod apparaît dans la liste des plugins.

2. Activer ou désactiver

Chaque mod a un interrupteur dans Préférences → Plugins. Un mod désactivé ne consomme rien : l’instance est détruite à la désactivation. Un mod déjà chargé est rechargé sans redémarrage via « Recharger ».

3. Retirer

Le bouton « Supprimer » d’un mod efface son fichier après confirmation. Il ne fonctionne que pour les mods du dossier utilisateur : les plugins livrés avec l’application ne sont jamais supprimés. Vous pouvez aussi supprimer le fichier à la main, puis relire le dossier.

4. Dépanner

  • Journal : menu Outils (ou palette) → « Ouvrir le journal des plugins ». Les erreurs de chargement et celles des plugins y sont écrites (%APPDATA%\Floral Player\plugins.log).
  • Deux fichiers pour le même plugin : un plugin est identifié par son id, le premier chargé l’emporte. Le dossier de l’application passe avant le dossier utilisateur.
  • Désactiver au lancement : la variable EMBER_PLUGINS_OFF=id1,id2 empêche l’activation de plugins précis.

Exemple : Discord

Le plugin Discord affiche la piste en cours (titre, artiste, album, durée écoulée, « En pause » le cas échéant) ainsi qu’un bouton vers le projet. Il nécessite l’application Discord ouverte sur le même ordinateur. Si rien n’apparaît, le journal indique « connecté » ou le motif du refus de Discord.

Idées de plugins à créer

Pistes réalisables avec l’API actuelle (événements de lecture, ticks, actions, panneaux, réglages). Aucun de ces plugins n’existe encore : ce sont des idées de départ.

  • Now playing pour OBS : écrit le titre, l’artiste et la pochette dans un fichier lu par OBS pour un stream.
  • Minuterie de sommeil : fondu puis arrêt après N minutes (un script .rhai suffit).
  • Scrobbler Last.fm : sur le modèle du plugin ListenBrainz.
  • Notifications Windows : une notification à chaque changement de piste.
  • Bilan d’écoute : statistiques exportées en CSV ou en page HTML (« Wrapped » annuel).
  • Réveil musical : lance une playlist à une heure donnée, avec volume progressif.
  • Télécommande web : une page pour piloter la lecture depuis un téléphone sur le réseau local.
  • Touches multimédia et Windows : affichage dans le panneau de volume de Windows.
  • Radio infinie : ajoute à la file des pistes proches de celle en cours (genre, année, artiste).
