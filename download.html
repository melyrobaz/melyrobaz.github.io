Installation

Six étapes, de la release au premier ajout de dossier.

  1. Télécharger la dernière release

    Utilisez le bouton ci-dessus ou la page GitHub Releases. Choisissez un fichier publié par l’auteur du dépôt.

  2. Décompresser si nécessaire

    Si la release fournit une archive, extrayez-la dans un dossier stable, par exemple C:\Program Files\FloralPlayer ou %LOCALAPPDATA%\Programs\Floral Player. Évitez de lancer l’application depuis une archive ZIP ouverte temporairement.

  3. Lancer l’application

    Double-cliquez sur FloralPlayer-Slint.exe (ou sur l’installateur fourni, qui crée les raccourcis et l’entrée de désinstallation).

  4. Traiter l’avertissement SmartScreen

    Si Windows affiche « Windows a protégé votre PC », cliquez sur Informations complémentaires, vérifiez le nom de l’éditeur et la provenance du fichier, puis sur Exécuter quand même uniquement si vous faites confiance à cette release.

  5. Ajouter votre musique

    Au premier lancement, ajoutez un ou plusieurs dossiers à la bibliothèque. FloralPlayer lit les fichiers que vous désignez et peut surveiller les dossiers pour détecter les ajouts. Aucun import vers un service en ligne n’est effectué.

  6. Configurer ce dont vous avez besoin

    Les intégrations (Discord, ListenBrainz, Soulseek, télécommande LAN) sont optionnelles. Vous pouvez utiliser le lecteur entièrement hors ligne, sans configurer la moindre connexion.

Mises à jour : l’application vérifie une fois par jour si une version plus récente existe (désactivable). Elle ne télécharge rien sans votre accord, vérifie l’empreinte SHA-256 de l’installeur avant de le lancer, et conserve vos réglages et playlists.

Exigences et précautions

SmartScreen et signature

FloralPlayer n’est pas signé par un certificat de signature de code commercial. Windows peut donc afficher un avertissement, même pour une release légitime. Ne désactivez pas SmartScreen globalement : contournez l’avertissement fichier par fichier, après avoir vérifié la source.

  • Windows 10 ou Windows 11, en 64 bits.
  • Un dossier accessible en écriture pour les caches et les réglages.
  • Les fichiers audio restent où ils sont : aucune copie n’est imposée.
  • Connexion Internet facultative, sauf pour les intégrations réseau.

Vérifier le fichier

Avant d’exécuter un fichier téléchargé, comparez son nom et sa date avec la page de release du dépôt. En cas de doute sur la provenance, ne l’exécutez pas.

Ce qui reste sur votre machine

  • La bibliothèque, les playlists, les notes, les statistiques d’écoute et les signets.
  • Les réglages, thèmes, dispositions de fenêtre et caches de pochettes ou de crêtes.
  • Les fichiers audio eux-mêmes : FloralPlayer ne les déplace pas sans action de votre part.

Les données de l’application sont stockées dans %APPDATA%\Floral Player. Les caches peuvent représenter plusieurs centaines de mégaoctets selon la taille de la bibliothèque.

Soulseek : téléchargement, pas partage de bibliothèque

Le client Soulseek intégré au code actuel sert à rechercher et télécharger des fichiers. Il ne configure aucun dossier de partage et ne publie pas votre bibliothèque locale. Les transferts terminés arrivent dans %USERPROFILE%\Music\Floral Downloads, puis sont renommés sans collision.

Lecture et accès aux fichiers

FloralPlayer ouvre les fichiers que vous ajoutez, lit leurs métadonnées et écrit des caches de pochettes, de crêtes et de ReplayGain. Une DLL de plugin s’exécute dans le même processus et n’est pas sandboxée : elle peut accéder à ce que votre compte Windows peut lire.

Mise à jour et suppression

Remplacez le binaire par la nouvelle release, ou utilisez l’installateur. La désinstallation conserve %APPDATA%\Floral Player par défaut ; l’option -RemoveData de l’installateur permet de l’effacer explicitement.
